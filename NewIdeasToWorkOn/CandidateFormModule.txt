I want to implement a new **Public Job Application and Candidate Form Module** in my existing recruitment platform.

IMPORTANT:

Before changing or writing any code, first analyze my complete existing project architecture.

I already have modules such as:

* Candidates
* Candidate Profiles
* Job Openings
* Interviews
* Forms or Assessments if already implemented
* Authentication
* User roles
* Resume upload or parsing functionality, if available
* Candidate communication functionality, if available

Do not immediately start implementing.

First inspect the existing code and understand how the current Candidate, Job, Interview, and Profile modules work.

The goal is to build this feature as part of the existing system and NOT as a separate application.

---

# MAIN BUSINESS REQUIREMENT

I want recruiters, clients, or authorized users to be able to create a **Job Application Form**.

This form can then be shared publicly with candidates.

The candidate should be able to:

1. Open a public application link.
2. Fill in their contact and profile information.
3. Upload their resume.
4. Fill additional questions configured by the recruiter.
5. Submit the application.

After submission, the system should automatically:

Candidate submits application
↓
Application is validated
↓
Resume is uploaded
↓
Candidate record is created or matched with an existing candidate
↓
Candidate profile is automatically populated
↓
Resume is attached to the candidate
↓
Application is linked to the Job Opening
↓
Application status is created
↓
Recruiter can review the candidate
↓
Recruiter can communicate with the candidate
↓
Candidate can move into the interview process

This should be the main architecture.
