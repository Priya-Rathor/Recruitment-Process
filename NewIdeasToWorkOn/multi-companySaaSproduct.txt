PHASE 12 — MULTI-TENANT API SECURITY
====================================================

This is extremely important.

Every protected API request must validate:

1. User authentication.
2. Organization membership.
3. User role/permissions.
4. Resource ownership by organization.

Example:

User requests:

GET /candidates/{candidateId}

The backend must verify:

- User is authenticated.
- User belongs to an organization.
- Candidate belongs to that organization.
- User has permission to access candidates.

Never trust organization_id directly from the frontend without validation.

Do not allow a user to change an organization_id in a request and access another company's data.

Create or extend middleware/services to enforce tenant isolation.
